# Homebrew tap for Trust Run

[Trust Run](https://trustrun.app) is a quiet Mac menu-bar app that warns you when code your AI wrote
opens your secret keys or talks to a server it should not. It runs on your Mac and sends nothing anywhere.

```bash
brew install --cask zlotecki/trustrun/trust-run
```

Apple silicon Macs only. Signed and notarized by Apple. 14-day free trial, then $39/year or $4.99/month.
